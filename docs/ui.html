Editor UI API

Compose controls. Let layout place them.

Build a component tree each frame, then render it into one rectangle. Rows, columns and panels measure their children and choose their positions. Lisp owns painting and behavior; native services measure layout and track pane dragging.

The editor imports editor/ui/components.lisp. New editor modules can use these functions directly or import that module. These are editor APIs, outside pixels; exported games do not include the editor library. The older coordinate-based widgets remain available for custom canvases.

A reusable component

(init! :clicks 0)
(init! :enabled true)

(defn counter-controls [title]
  (ui/column (map :gap 12)
    [(ui/label title)
     (ui/row (map :gap 8 :align "center")
       [(ui/label (str "Count: " (get :clicks)))
        (ui/flex)
        (ui/with (map :disabled (not (get :enabled)))
          (ui/button :add-click "Add"
            (fn [] (set! :clicks (+ (get :clicks) 1)))))])
     (ui/toggle :enable-counter "Enable counter" :enabled)]))

(defn counter-window []
  (ui/dialog :counter-window "Counter" 400 240
    (counter-controls "A reusable component")))

Call counter-window from the editor's render hook to show it. Constructors produce temporary component values; ui/render performs layout, painting and event handling once. Stable control IDs preserve keyboard focus. Button callbacks run on pointer press or keyboard activation. Store values in state and rebuild the tree next frame; do not persist component trees or callbacks with set!.

Components

Function Behavior
(ui/row options children) Places children horizontally.
(ui/column options children) Places children vertically.
(ui/panel options children) A themed background containing a column.
(ui/label caption), (ui/muted caption) Text measured and painted by the component.
(ui/button id caption action) A button with a zero-argument callback.
(ui/toggle id caption key) A boolean state control.
(ui/slider id caption key low high) A numeric state slider using pointer capture and accessible range input.
(ui/code tab) The editor's source-input component. Use one active source input per view.
(ui/space height), (ui/flex) Fixed vertical space or flexible remaining space.
(ui/scroll id key options children) A clipped vertical list with wheel scrolling and a draggable scrollbar. The key stores its offset.
(ui/custom options paint) An adapter for custom components. The callback receives origin and size.
(ui/with options component) Overrides selected options, preserving the component's other options.
(ui/render origin size component) Renders one tree inside a clipped root rectangle.
(ui/dialog id title width height content) A centered, viewport-bounded tool window with a title and close button.

Layout options

:gap defaults to 8 pixels. :padding accepts one number or [top right bottom left]. :width and :height set explicit dimensions. :grow shares the remaining space by weight along the parent's main axis. :align sets cross-axis placement to "start", "center", "end" or the default "stretch". Text and controls otherwise use their natural size. Buttons accept :active and :disabled; labels accept :tone "muted"; panels accept :color.

Rows do not wrap; overflow is clipped. Use nested rows or a scroll container for larger content. Null/false children let conditional controls disappear without reserving space. A tree is bounded to 512 components and 32 levels, and control IDs must be unique within a tree.

Dockable panes

(init! :example-docks (map))

(defn example-workspace []
  (ui/dockspace :example-docks [0 51]
    [(screen-width) (- (screen-height) 81)]
    [(ui/pane :settings "Settings" (map :dock "left" :extent 280)
       (counter-controls "Settings"))
     (ui/pane :main "Main" (map :dock "center" :fixed true)
       (ui/column (map :padding 16)
         [(ui/label "The center uses the remaining space.")]))]))

ui/pane receives a stable ID, title, options and a component. ui/dockspace receives a state key, workspace bounds and a pane vector. Dock positions are "left", "right", "top", "bottom", "floating" or "center". :extent is pixels, or a fraction at most 1 of remaining workspace size. :visible false hides a pane without forgetting its saved placement; :fixed true reserves a center surface. Optional :collapsed, :collapse-id and a zero-argument :collapse callback add a collapse control. Optional :hide-id and a zero-argument :hide callback add a Close icon button. Docked panes minimize to a bottom bar with an icon, title, restore chevron and close button. Click the title or up chevron to restore the saved split and dimensions. The optional :icon chooses the minimized pane's asset icon. Floating panes minimize into the same bottom bar and preserve their position and dimensions.

Drag a pane's title to float it. Move to an outer workspace edge to preview docking and hold still for 700 milliseconds and release to attach it. A light gray preview fills blue as the timer advances, then turns green when release will dock. Releasing early keeps the pane floating. Movement beyond a small jitter allowance or changing targets restarts the timer. Drop near the left, right, top or bottom of a docked pane to split that pane's area; the highlighted half shows the result. Splits can be nested. The central part of a pane is a neutral drop zone for keeping a dragged pane floating. Grab a floating pane's edges to resize it, or drag the divider between docked panes to resize both neighbors. Resize cursors indicate the available direction. Escape cancels a drag. Clicking or otherwise interacting with floating content brings that pane to the top. Panes use a down chevron to minimize into the bottom bar, and an up chevron to restore their previous size. Detaching a pane reduces its width and height by 10% and leaves room around its edges to resize it. Newly opened floating panes are centered in the workspace. Positions and dimensions live in a JSON-compatible map under the supplied state key, so project saves and reloads retain dimensions, split ratios and floating stacking order. Hiding a pane frees its area without deleting its saved split; dragging it out removes its old leaf and fills the gap. Panes do not group into tabs.

The editor uses this API for Files, Code, Game, Inspector and Generators panes. Game starts in the center and can dock, float, collapse or hide. Restore a hidden Game pane through View → Game; its saved placement is retained. Code fills the freed center space when Game is hidden, collapsed or moved. Hiding Game leaves gameplay running; F4 temporarily focuses the preview even when its pane is hidden. Desktop layouts dock; narrow windows use the compact editor layout and preserve desktop placements. View → Reset pane layout returns panes to their default docks. The canvas-size dialog, About dialog, command palette, code pane and game pane demonstrate component composition in ordinary editable Lisp files.

Opening a generator file starts a floating inspector. Drag its header to dock or split it, use its chevron to collapse it, and its X button to close it. Next switches the inspected generator while preserving placement; Code opens its source in the main Code pane. Preview, annotated fields and output actions resize with the inspector. View groups all pane visibility toggles first, then layout actions, tools and recovery.

To update an existing project, press F2 and choose Project → Use latest editor. Customized editor files are preserved as backups.
