Documentation / 0.1

One language for your game and its tools.

aioli is a live, pixel-first game workshop. Write gameplay, synthesize sounds, draw with shaders, and change the editor itself in Lisp.

The editor is a fullscreen app written in the same language as your gameplay. Its buttons, source view, and tool controls paint pixels on a WebGPU canvas. Editing the editor is part of the normal workflow.

Start with a small pixel program

(defpixel render [p time]
  (background "#101613")
  (fill "#bbd6a6")
  (circle [160 120] (+ 24 (* 4 (sin time)))))

Open the workshop, open View → Files pane, expand examples/, and select garden.scene.lisp, replace its source with this program, and press Ctrl + Enter (or Cmd + Enter). The game view renders a 320 × 240 surface. Drawing coordinates begin at the top left.

Two entry points, ordinary project files

File or folder Purpose
main.lisp The editor application, importing its workspace and UI.
game.lisp The embedded application entry, selecting the initial scene.
examples/*.scene.lisp Playable scenes combining CPU functions and a render shader.
examples/generators/*.generator.lisp Image, audio and text recipes with generated inspectors.
examples/commands/*.command.lisp Explicit editor/game state actions and export samples.
editor/ Editable panes, reusable UI and ordinary PNG icons.

The editor can inspect game code and state; the game cannot access editor state or capabilities. File suffixes are editor conventions. The runtime loads explicit imports, regardless of suffix. See Projects and tools for generators, commands and standalone HTML export.

Browser requirements

The workshop requires a browser and device with WebGPU support, served over HTTPS or localhost. These documentation pages work without WebGPU and need no JavaScript.

This is a focused prototype. The Lisp shader subset is smaller than the gameplay language. The procedural tools edit recipes through code and controls; full node graphs and persistent GPU feedback are not available yet.
