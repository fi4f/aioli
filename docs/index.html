Documentation / 0.1

One language for your game and its tools.

aioli is a live, pixel-first game workshop. Write gameplay, synthesize sounds, draw with shaders, and change the editor itself in Lisp.

The editor is a fullscreen app written in the same language as your gameplay. Its buttons, source view, and tool controls paint pixels on a WebGPU canvas. Editing the editor is part of the normal workflow.

Start with a small pixel program

(defpixel hello [p time]
  (background "#101613")
  (fill "#bbd6a6")
  (circle [160 120] (+ 24 (* 4 (sin time)))))

Open the workshop, select the scene tab, replace its source with this program, and press Ctrl + Enter (or Cmd + Enter). The game view renders a 320 × 240 surface. Drawing coordinates begin at the top left.

Five editable sources

Tab Purpose
scene A per-pixel program compiled into WGSL.
game State initialization and (defn update [dt] ...).
audio A sound function that emits procedural voices.
editor The fullscreen layout, drawing, and editor actions.
ui Ordinary Lisp functions implementing widgets and source painting.

Browser requirements

The workshop requires a browser and device with WebGPU support, served over HTTPS or localhost. These documentation pages work without WebGPU and need no JavaScript.

This is a focused prototype. The Lisp shader subset is smaller than the gameplay language. The procedural tools edit recipes through code and controls; full node graphs and persistent GPU feedback are not available yet.
