API reference

Draw, interact, compose.

The public Lisp APIs, grouped by what you are making. CPU APIs run in gameplay/editor/audio functions; shader APIs run inside a pixel program.

In game scripts and scenes, (canvas-width) and (canvas-height) return the logical project canvas size from any lifecycle or drawing hook. (screen-width) and (screen-height) return the same size in games, but return the browser workspace size in the editor. Inside pixels [p time], use the built-in symbols width and height, or the canvas size calls; these values are live GPU uniforms, independent of browser scaling.

Drawing primitives

Positions are [x y], sizes are [width height], and colors are "#RRGGBB", "#RRGGBBAA", RGB vectors, or RGBA vectors with components in [0, 1]. CPU drawing is available while the editor function runs. Coordinates begin at the top left; x grows right and y grows down.

Call Context Behavior
(background color) CPU + shader Paint the background. Normally called at the beginning of the frame/program.
(fill color) CPU + shader Set the paint for subsequent primitives.
(rect origin size) CPU + shader Evaluate a filled rectangle's coverage.
(circle center radius) CPU + shader Evaluate coverage within the radius. Edges are crisp.
(line start end width) CPU + shader Draw a thick segment with round ends.
(opacity amount) CPU + shader Set opacity, clamped to [0, 1].
(blend :over) CPU + shader Alpha-over, the default. Also supports :add and :multiply.
(translate offset) CPU + shader Move subsequent drawing by a 2D offset.
(scale amount) CPU + shader CPU: a positive scalar. Shader: a scalar or 2D vector; use nonzero components.
(rotate radians) Shader Rotate around the current origin.
(scope body...) CPU + shader Restore position/transform, fill, opacity, and blend settings after the body. Already drawn pixels remain.
(text origin value) CPU editor Draw fixed-width text. Current glyph coverage is ASCII 32–126; other characters display as ?. Newlines and tabs are supported. The source editor retains Unicode in its buffer and clipboard; each fallback character occupies one displayed cell, and a tab occupies four.
(clip origin size) CPU editor Intersect the current clipping rectangle. Use scope to restore it. Specify bounds in the editor's screen coordinate system.
(surface origin size) CPU editor Composite the project canvas texture with nearest-neighbor sampling. Also declare its game-input region.
(waveform origin size) CPU editor Draw the synthesized audio patch's min/max amplitude using the current paint. 
; Inside a drawable's pixels body:
(scope
  (translate [160 120])
  (rotate (* time 0.2))
  (blend :add)
  (opacity 0.5)
  (fill "#bbd6a6")
  (rect [-20 -20] [40 40]))

Shader drawing updates local state for each pixel invocation. CPU editor drawing emits ordered primitives that are also evaluated per pixel. Neither submits geometry for each shape. CPU state mutations such as set! are not undone by a drawing scope.

Nested GPU pixels

(pixels [p time] color-expression-or-drawing-body...) emits a procedural GPU material in the current draw stream. It inherits outer transforms, clipping, opacity and blending, and composes in painter order. Drawable parameters, lexical numbers/colors, and state reads become per-invocation uniforms. p is local pixel position; width/height are logical canvas dimensions. Each block permits at most 63 uniform slots and 4096 expanded statements; a frame permits 32 distinct programs. Identical programs with different argument values share compiled code and retain separate uniforms. See the unified drawing guide for syntax, capture rules and GPU restrictions. Inline drawable previews render both shapes and pixels on the annotated canvas without changing live state.

Shader math

Expression Meaning
p, p.x, p.y, (position) Current transformed pixel position.
time, width, height Seconds and logical scene dimensions.
(get :key) Read an initialized state value as a uniform.
(vec2 x y), (vec3 x y z) Construct a numeric vector. Literal [x y z w] can construct four components.
(rgb r g b), (rgba r g b a) Color vectors. RGB is made opaque when used as a paint.
+ - * / Scalar or compatible vector arithmetic.
sin cos abs floor fract Component-wise math; fract is the fractional part.
(length vector) Vector magnitude.
dot cross normalize reflect sqrt Shader vector math for lighting and rays. dot and reflect take two matching vectors; cross takes two 3D vectors. normalize takes a vector, and sqrt is component-wise.
local.x, local.yz, local.xyz Read components of shader-local vectors.
(noise vec2) A deterministic 2D hash in [0, 1), not smooth noise.
(grid-ray origin direction rows) GPU DDA traversal of a rectangular grid, at most 64×64. Both vectors are 2D; zero cells are empty, digits 1–9 are solid materials. Returns [distance side material texture-u], with side 0 for an X crossing and 1 for a Y crossing. Distance multiplies the supplied direction (do not normalize camera-plane rays when using it as perpendicular depth). Bind string rows outside pixels, provide literal rows, or read a state vector with (get :key). Grids are embedded in the shader.
(min a b), (max a b), (pow a b) Component-wise functions with compatible types.
(mod a b) a - b * floor(a / b).
(clamp value low high) Restrict components to a range.
(mix a b amount) Linear interpolation. Does not automatically clamp amount.
(step edge value) Zero below the edge, one at or above it.
(smoothstep low high value) Smooth transition from zero to one. 
(defdraw grain []
  (pixels [p time]
  (background "#101613")
  (fill (mix [0.1 0.2 0.15] [0.7 0.8 0.6]
             (noise (* p 0.1))))
  (rect [0 0] [width height])))

The compiler supports a maximum of 63 state parameters and bounded shader expansion. Expressions must satisfy WGSL type rules; errors keep the previous shader active.

Gameplay and state

Define (defn update [dt] ...) in game. It runs each unpaused frame, with dt measured in seconds and capped at 0.04 after a long browser frame. init!, set!, and get are described in the language guide. 

(init! :x 160)
(init! :speed 75)
(defn update [dt]
  (when (key? "d")
    (set! :x (+ (get :x) (* (get :speed) dt)))))

(key? name) returns true for a held gameplay key while the game view has focus. Currently captured keys are "a" "d" "w" " " "ArrowLeft" "ArrowRight" "ArrowUp". Letter keys are lowercase. Source typing does not drive gameplay.

Lisp widget library

These are normal functions imported by editor/ui/components.lisp from editor/ui/, not special language forms. Call them from editor; changing their definitions changes the editor live.

Signature Use
(ui-button id caption origin size active) Paint and register a button. Returns true on pointer press or accessible activation. active selects its highlighted appearance.
(ui-tab id caption x active-tab) Draw the stock source tab at y=58 and update :tab on activation.
(ui-slider id caption key x y width low high) Bind a slider to a numeric state key; the stock value display is a percentage.
(ui-number-slider id caption key x y width low high) Same binding, displaying a number to two decimal places.
(ui-toggle id caption key x y width) Toggle a boolean state key.
(ui-choice id caption key choices x y width) Cycle through a vector of choices.
(code-editor origin size tab) Paint source text, syntax colors, selection, and caret from buffer data. 
; Add inside the existing editor function:
(when (ui-button :center "Center" [24 100] [100 32] false)
  (set! :x 160))

(ui-number-slider :my-radius "Radius" :moon
                  24 160 220 4 40)

Use a stable, unique ID per control. Initialize slider/toggle/choice keys before drawing. Hit regions use screen coordinates; drawing transforms do not automatically transform input bounds.

Editor input

Call Behavior
(screen-width), (screen-height), (canvas-width), (canvas-height) Editor viewport dimensions in CSS pixels.
(pointer-x), (pointer-y) Screen pointer position.
(pointer-pressed?) True during the frame that consumes a pointer press.
(pointer-down?) True while the pointer remains held.
(hit? origin size) Pointer is inside the bounds and not covered by a higher interaction region.
(capture! id), (captured? id) Keep a drag assigned to a control until release.
(region id label origin size) Declare interaction/accessibility bounds. Regions later in painter order take priority.
(region id label origin size key low high) Declare a numeric slider region with an accessible state binding.
(activated? id) Accessible keyboard/screen-reader activation in this frame.
(focused? id) Whether an accessible control has focus.

Pointer actions are suppressed while a candidate editor is being validated; evaluation checks must not click controls or trigger exports. Use the widget library unless you are implementing a new control.

Source buffers

Most projects should call code-editor. The following primitives allow an alternative source widget. They supply data only; editor/ui/code-input.lisp paints the visible content.

Call Returned data
(buffer-open origin size tab) Select a project source buffer and lay out its input region. Entry buffer keys are main game; other files use their project paths. Read-only buffers: wgsl guide diagnostic.
(buffer-rows) Vector of [number-position number-text segments]. Each segment is [position text kind].
(buffer-hooks) Visible inline preview rows: [origin size name kind], where kind is "draw" or "sound". These rows appear above top-level definitions without modifying source text or source line numbers. Transient and read-only buffers have no hook controls.
(inspect-inline-hook name) Open the named hook preview from the current source buffer, using copied state.
(buffer-selections) Vector of [origin size] selection rectangles.
(buffer-caret) A position, or nil while hidden/blinking off.

Token kinds are comment string keyword number delimiter symbol whitespace. (token-color kind) in editor/ui/code-input.lisp chooses colors. Buffer text is displayed even when it cannot yet be evaluated.

Inspectable drawing and sound hooks

(defdraw badge [x y]
  ["Badge" [160 120] [320 240]]
  (scope
    (fill "#bbd6a6")
    (circle [x y] 20)))

(defsound jump [pitch]
  ["Jump" [300]]
  (voice :sine pitch (* pitch 3) 0.15 0.3))

(defdraw render [] (badge 160 120))
; Call this from gameplay:
; (play-sound :jump 300)

defdraw and defsound define ordinary callable Lisp functions. Drawing hooks may contain nested GPU pixels blocks; defdraw render [] is the primary render entry point. Drawing hooks can call other drawing hooks; sound hooks can mix recipes by calling other sound hooks. Use scope to restore drawing settings around a component. The optional annotation is ["Title" [argument defaults] [canvas width height]]. Omitted argument defaults are zero; the default preview canvas is 320 by 240. Explicit defaults must match the function's argument count. Canvas dimensions are 1–4096.

Open the source and click Preview draw or Preview sound directly above its declaration to inspect it. The button row is editor UI; copying, saving, line numbers and Lisp evaluation use the original source. Click Code to return to the same source buffer. The editor executes only that hook against copied state with application actions and input disabled. Drawing previews start with fresh drawing state and a blank canvas. Edit the JSON argument array and click Preview to rerun it. Sound previews provide a waveform, play/pause, stop, a one-second forward button and click/drag seeking. Preview state never changes the game. These declarations work in exported apps; only inspection UI belongs to the editor.

Procedural audio

(defn sound []
  (voice :sine 440 880 0.3 0.35)
  (voice :triangle 220 440 0.3 0.08))

(voice waveform start-hz end-hz duration gain) adds a voice to the current patch. Waveforms: :sine :triangle :square :sawtooth :noise, or equivalent strings. Frequencies must be 1–20000 Hz, duration 0.01–5 seconds, and gain 0–1. A sound function must emit 1–16 voices.

Voices sweep frequency linearly, apply a short attack/release, and mix into mono audio at 44.1 kHz with soft clipping. Noise is seeded and reproducible. (play-sound) auditions the current patch; (play-sound :jump 300) plays a named defsound hook with arguments; (export-wav) downloads it as PCM WAV. Playback may require a browser gesture first: click the game or Play control. 

(init! :pitch 440)
(defn sound []
  (voice :sine (get :pitch) 880 0.3 0.35))

A Lisp slider bound to :pitch and a code edit both change the same recipe. The generator inspector supplies controls from annotated state fields, while the inline preview buttons previews individual named sound recipes.

Editor actions

Call Action
(evaluate-project) Evaluate all source buffers and compile the scene.
(reset-project) Evaluate with fresh state.
(export-project), (import-project) Save/open project JSON, including sources and state.
(play-file path), (playable-file? path) Play a scene, or restart game.lisp with fresh application state; available only to the editor.
(scene-fields), (scene-field-value key), (set-scene-field key value) Inspect state belonging to the active scene (or game.lisp when no scene is running) using the shared annotation schema.
(export-html) Validate and download an offline HTML application, with game files and assets.
(game-state), (game-get key), (game-set! key value) Inspect or modify embedded application state. Available only to the editor.
(game-code path), (game-definitions), (game-call name ...args) Inspect source and definitions, or call a game function using data arguments.
(export-png) Download the game image, excluding editor chrome.
(open-docs) Open this documentation site in a new tab.
(status), (error?) Current status text and error flag.

These actions take effect for the active editor rather than during validation. The stock editor also uses shared keys such as :tab, :show-code, :show-tools, :tool, :menu, and :paused. Set them in an editor action to control the stock layout.

Named files, generators and commands

See the project API reference for file operations, generator previews and exports, and palette commands. Use (set! :show-files true) to show the file pane. Use (open-generator path) to open a floating, dockable inspector and (close-generator) to close it. Set :window to "palette" to open the command palette; set it to "" to close it.

Image generators use defdraw render; audio generators use generate-sound; text generators declare (generator :text "Title" "output.txt") and return a string from generate-text. All use annotated init! fields for inspector controls. Text preview/save APIs and filename rules are detailed in the text generator reference.

Menus and source editing

(edit-buffer action) accepts :undo, :redo, :cut, :copy, :paste, or :select-all. (can-edit-buffer? action) reports whether the action is available. (prepare-file-path) opens new-file path entry; pass true for renaming the selected file. (selected-file?) and (selected-file-removable?) support enabled states. (open-recovery) enters recovery.

(menu-region id label origin size enabled checked) declares a menu interaction/accessibility region. Pass nil for an ordinary item, or a boolean checked state for a checkbox item. (pointer-moved?) is true for one frame after pointer movement. The stock menu helpers in editor/ui/menu.lisp and editor/menu-bar.lisp paint headings, items, separators and the dismissible dropdown.

Code tabs

(open-code-tab key) selects or adds a buffer; (close-code-tab key) closes its tab without deleting its source. Use short keys for the main/game entry files, or a full project path for other sources. (code-tabs width) returns visible rows [key label x-offset width draft?] and updates overflow metadata. (code-tabs-before?) / (code-tabs-after?) query that metadata; (scroll-code-tabs delta) browses overflow. (active-code-path) returns the selected buffer's project path. Shared state :open-tabs stores a JSON array of keys; :tab remains the active key. Selecting a key with Lisp also opens its tab.

Asset preview services

(open-file path) opens source tabs, generator inspectors, or image/audio/text resource previews. (asset-ready?) and (asset-status) report decode readiness/errors; (asset-width) / (asset-height) give decoded image dimensions. (asset-image origin size) samples the decoded image in the pixel drawing stream. The stock window uses :preview-path, :preview-zoom and :preview-pan-x / :preview-pan-y. Zoom multiplies the fitted size; pan is measured in screen pixels.

(asset-waveform origin size) draws the decoded audio envelope with the current fill color. (asset-duration) and (asset-time) return seconds; (asset-playing?) reports transport state. (play-asset), (pause-asset), (stop-asset) and (seek-asset seconds) control playback. (close-asset-preview) stops playback and closes the window. These services do not modify project resources.
